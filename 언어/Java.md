추가 개념 : [[JDK]]

썬 마이크로시스템즈에서 1995년에 제임스 고슬링에 의해 개발된 [[객체지향]] 프로그래밍 언어입니다.\
(최초 발표 : 1995년 5월 23일 / 정식 출시 1996년 1월 23일)

## Java의 3가지 에디션

- Java SE (Java Standard Edition / J2SE)
	- **대다수의 사람들이 가장 많이 접하는 표준 에디션**입니다. Java의 핵심 API와 기능들을 제공합니다. 
- Jakarta EE, 구 Java EE (Java Enterprise Edition / J2EE)
	- **기업에서 운영하는 서버 페이지에 특화된 에디션**입니다. JSP와 서블릿을 비롯한 웹 애플리케이션 서버에 관련된 기술들이 포함되어 있습니다.
- Java ME (Java Micro Edition / J2ME)
	- 셋톱 박스, 센서 등의 **임베디드 시스템 환경에 특화된 경량 에디션**입니다.

## 특징

- 플렛폼에 독립적인(cross-platform) 언어입니다.
	- 소스 코드를 하드웨어의 기계어로 직접 컴파일하여 링크하는 C/C++과 달리, 자바 컴파일러는 바이트코드인 클래스 파일(`.class`)을 생성하고, 자바 가상머신(Java Virtual Machine / JVM)이 바이트코드를 인터프리팅 합니다.
	- **그래서 자바는 컴파일러 언어와 인터프리터 언어의 특징을 가진 하이브리드 언어입니다.**
- Java로 작성된 프로그램은 적절한 JVM만 깔려있다면 운영체제 상관없이 대부분 문제없이 동작합니다.
	- 만약 플렛폼에 종속적이라면 Window 버전으로 빌드한 프로그램을 그대로 Linux, MacOS 등에서 실행하는 것은 불가능합니다.
	- Java가 플렛폼에 독립적이기 때문에 생기는 특징으로, 이는 바이트코드의 실행 주체가 운영체제가 아닌 JVM이기 때문입니다.
- 자바는 클래스 기반의 객체 지향 언어이고, 모든 객체에는 null이 대입될 수 있습니다.
	- 이로 인해, NPE와 같은 null에 의한 버그가 많이 발생하여 비판을 받아오고 있습니다.
