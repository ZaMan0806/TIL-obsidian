#important
## 개념
데이터(속성)와 기능(메서드)을 하나의 객체(Object)로 묶어 표현합니다.\
현실 세계를 객체 단위로 추상화해서 설계하고, 객체 간의 상호작용으로 프로그램이 구성됩니다.

## 특징
객체지향 관련 면접 질문으로 자주 등장하는 녀석들입니다.
- 추상화 (Abstraction)
	- 복잡한 시스템에서 핵심적이 개념이나 기능만 추출하는 것입니다.
	- 불필요한 세부사항은 감추고 필요한 속성과 동작만 클래스로 정의합니다.
	- 비유 : **설계도만 그리기**
- 캡슐화 (Encapsulation)
	- 데이터(속성)와 기능(메서드)을 하나로 묶고, 외부에서 접근하지 못하도록 숨기는 것입니다.
	- 비유 : **블랙박스로 감싸기**
- 상속 (Inheritance)
	- 기존 클래스(부모)의 속성과 메소드를 새로운 클래스(자식)가 물려받아 재사용하는 것입니다.
	- 코드 중복을 줄이고 확장성을 높입니다.
	- 비유 : **부모 거 물려받기 (유산..?)**
- 다형성 (Polymorphism)
	- 같은 이름의 메서드나 인터페이스가 상황에 따라 다르게 동작하는 것입니다.
	- 오버라이딩(Override, 재정의), 오버로딩(Overload, 중복정의)이 대표적인 예시입니다.
	- 비유 : **같은 명령이지만 다른 반응**
